# Audio del juego

Coloca aquí los archivos de audio licenciados o creados por el desarrollador.

```text
music/
  nivel-1.mp3
  nivel-2.mp3
  nivel-3/nivel-3.mp3
  final.mp3
sfx/
  jump.wav
  star.wav
  damage.wav
  attack.wav
  interaction.wav
  victory.wav
```

Mientras los seis efectos `.wav` no existan, el juego usa tonos breves generados con Web Audio. La música queda en silencio hasta que se proporcionen las cuatro pistas; no se emplean recursos externos ni música con copyright.
