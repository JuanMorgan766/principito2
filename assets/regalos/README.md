# Regalos

La galería contiene las seis imágenes proporcionadas (`gift1 (1).jpeg` a
`gift1 (6).jpeg`), registradas en `js/data/extraContent.js`. Se pueden recorrer
con anterior/siguiente o las flechas izquierda/derecha; al tocar una imagen se
abre ampliada y los controles siguen disponibles. También se puede cerrar el
visor con `Cerrar`, `Volver`, Escape o tocando de nuevo la imagen.

Para agregar otra imagen, colócala en esta carpeta y agrega su ruta y texto
alternativo al arreglo `giftImages`. Mantén las rutas locales; no se cargan
recursos externos.
